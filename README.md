# CS2300 Semester Programming Repository

Welcome to your **CS2300 Programming Assignments** repository!

This repository will be used for **all programming assignments** throughout the semester. Before beginning your first programming assignment, complete the setup steps below.

---

# Repository Setup (PA0)

Complete each of the following steps before submitting **PA0 - Github Setup**.

## Step 1 – Complete Your Information

Open the file:

```
student-info.txt
```

Complete all requested information and save the file.

---

## Step 2 – Review the Repository Structure

Your repository is organized as follows:

```
ProgrammingAssignments/
│
├── PA1/
├── PA2/
├── PA3/
├── PA4/
├── shared/
├── student-info.txt
└── README.md
```
## Repository Structure

This repository contains a folder for each programming assignment (`PA1`–`PA4`).

As programming assignments are released, complete your work in the corresponding folder.

> **Important:** Do **not** rename, delete, or move any of the assignment folders unless instructed to do so. Keeping the repository structure unchanged ensures that all programming assignments remain organized throughout the semester.

---

## Step 3 – Commit Your Changes

After completing **student-info.txt**, create your first Git commit.

A good commit message is:

```
Complete PA0 repository setup
```

---

## Step 4 – Push Your Changes

Push your commit to GitHub.

After pushing, verify that:

- Your updated `student-info.txt` appears on GitHub.
- Your commit appears in the repository history.

---

# Programming Assignments

For each programming assignment during the semester:

1. Open the appropriate **PA#** folder.
2. Complete the assignment.
3. Commit your work regularly.
4. Push your completed work to GitHub.
5. Submit the required information in Canvas (see each assignment for submission instructions).
